# Open sample dataset

The included `transactions.csv` is an **original synthetic** 12-record example released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). It contains no real customer data and no cloud provider billing data. `cloud_region` is a fictional source-region tag, not evidence that data was transferred between clouds. Values support repeatable ETL/API tests, not performance, governance, or cost claims.
